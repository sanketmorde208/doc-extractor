# Document Extraction Platform

A Python application to extract information from documents like PDF, DOCX, and TXT files.

## How to Run

```bash
pip install -r requirements.txt
python main.py
```

Then open http://localhost:8000 in your browser.

## Features

1. Text Extraction
2. Document Summarization
3. Keyword Extraction
4. Table Extraction
5. Image Metadata Extraction
6. Language Detection
7. Sentiment Analysis
8. Named Entity Recognition
9. Text Translation

## Supported Files

- PDF
- DOCX
- TXT
- Images (PNG, JPG)
